# DEF-004: "NEW" status badge on /account/messages fails WCAG colour contrast (1.95:1)

## Summary

On `/account/messages`, the status badge (`<span class="badge rounded-pill bg-info">NEW</span>`)
shows white text on `#0dcaf0`, a contrast ratio of 1.95:1. WCAG 2.2 AA 1.4.3 requires 4.5:1 for
12px bold text. axe reports this as `color-contrast`, impact serious.

## Steps to reproduce

1. Sign in as a user who has sent at least one message.
2. Open `/account/messages`.
3. Run an axe WCAG 2.2 AA scan, or measure the "NEW" badge's contrast.

## Expected

AC-10 states that the row shows Status "NEW". 02 requires that state to have no WCAG 2.2 AA
violations, so the status must be readable at at least 4.5:1 contrast.

## Actual

axe `color-contrast` (serious) on `.badge`: foreground `#ffffff`, background `#0dcaf0`, 1.95:1,
expected 4.5:1. Same on retry. Low-vision users may not be able to read the message status. The
rest of the row reads correctly.
